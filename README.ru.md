# lampa-filters: фильтрация подборок Lampa

Два варианта архитектуры:

1. **`lampa-filters.plugin.js` - автономный плагин (основной, без сервера)**:
   вся фильтрация на фронте. Добавляется как обычный плагин Lampa
   (Настройки -> Расширения -> Добавить плагин), работает в браузере и на
   Apple TV, никакой сервис не нужен.
2. `mock.py` + `mirror.sh` - вариант с локальным прокси/BFF (исторический,
   для отладки подмены ответов; поднимается `uv run --with fastapi --with
   httpx --with uvicorn mock.py`, порт 8180).

## Автономный плагин

- перехватывает ответы сетевого слоя через официальное событие `request_secuses`
  и фильтрует `results` во всех списках: цифровые релизы, каталог, главная, топ,
  коллекции, рекомендации; закэшированные ответы фильтруются так же; поиск не трогается;
- «Избранное» - отдельный набор правил, применяется обёрткой
  `Lampa.Favorite.get` (данные лежат на устройстве);
- настройки: **Настройки -> Фильтры подборок** - вкл/выкл, авто-выключение
  через 1/3/6/12/24 ч, рейтинг + источник (auto/TMDB/IMDb), годы от-по,
  качество 4K/webdl/bdrip (экранка ts/tc отсеивается всегда), включающие и
  исключающие жанры, отдельный блок для избранного;
- конфиг хранится в localStorage устройства (`lampa_filters`).

Проверка логики: `node /tmp/test-lampa-filters.js` (заглушки Lampa/jQuery,
8 проверок: фильтрация, поиск, cub-лента, таймер, избранное, годы).

лечится выключением «Кэширования запросов» в настройках Lampa или разовой
очисткой данных сайта. Страницы списков становятся короче (20 -> K),
пустых практически не бывает.

## Запуск мока (вариант 2)

```sh
cd ~/Projects/local/lampa-filters
uv run --with fastapi --with httpx --with uvicorn mock.py
```

Открывать: **http://127.0.0.1:8180/** (зеркало фронта, плагин вшит в index.html
и включается сам). Статус-страница: http://127.0.0.1:8180/__mock/

Зеркало обновляется при новых версиях фронта: `./mirror.sh` (36 файлов статики).

## Что умеет мок

| URL | Что делает |
|---|---|
| `/` | зеркало фронта lampa.mx (index.html + плагин авто-подключён) |
| `/3/<path>` | прокси на `apitmdb.cubnotrip.top/3`; списковые с `?mock=1` - маркер на page=1 |
| `/releases?page=N` | прокси cub-ленты релизов + фильтр; маркер на page=1 |
| `/filters`, `/filters/on`, `/filters/off`, `POST /filters` | пресет и переключение |
| `/settings` | страница настройки: форма фильтров подборок, блок избранного, таймер авто-выключения |
| `/__mock/` | статус: лог запросов, кэш, предзагрузка |

**Кэш и предзагрузка**: все списковые ответы кэшируются (TTL 600 c), при запросе
страницы N в фоне догружаются страницы N+1..N+10 (`PREFETCH_AHEAD` в mock.py,
параллельность 4). Смена фильтров чистит кэш. Проверено: повторный запрос страницы
1-3 мс против 1.6 c у апстрима.

## Пресет (переменная FILTERS в mock.py)

- `rating_min: 7.0`, `rating_source: auto` (TMDB при 10+ голосах, иначе IMDb)
- `exclude_genres: [27]` (ужасы), `include_genres: []` (любой)
- `year_from` / `year_to`: диапазон годов, `null` = выключено
- `quality: ["webdl", "4k"]`, экранка `ts`/`tc` отбрасывается всегда,
  карточки без данных о качестве пропускаются (`keep_unknown_quality`)

## Страница настройки `/settings` и таймер

Форма: включение фильтра подборок, рейтинг (источник auto/tmdb/imdb), годы
от-до, качество чекбоксами (4K/webdl/bdrip; экранка ts/tc отсеивается всегда),
исключающие и включающие жанры (русские названия, TMDB id), пропуск карточек
без качества, авто-выключение через N часов (по умолчанию 12). Статус сверху
показывает обратный отсчёт. Кнопка «Выключить сейчас» - мгновенное отключение.
Смена пресета чистит кэш; плагин обновляет правила раз в 60 с.

## Избранное

Отдельный блок на `/settings`: правила для избранного независимы от фильтра
подборок. Применяются не на сервере, а в плагине (избранное хранится локально
на устройстве): обёртка `Lampa.Favorite.get` фильтрует карточки и пишет в
консоль `favorite.get N -> M`. Качество фильтруется, если карточка его хранит
(при добавлении из cub-списков оно есть).

## Чек-лист браузерного теста

1. Открыть `http://127.0.0.1:8180/` - фронт Lampa загрузился с локальной машины
   (жёлтая строка `[lampa-mock] активен` в консоли не нужна - плагин уже внутри).
2. Главная/Каталог: списки грузятся, сверху page=1 карточка «MOCK: подмена работает».
3. «Цифровые релизы»: отфильтрованный список, первой маркер-карточка;
   в `/__mock/` видно `filter 20->K`, `prefetch pages ... loaded ...`.
4. Листать вниз: страницы 2, 3, 4... отдаются мгновенно (кэш предзагрузки).
5. «Избранное»: в консоли `[lampa-mock] favorite.get -> N карточек`
   (на новом origin избранное пустое - войти в cub-аккаунт через Настройки).
6. Открыть карточку фильма: описание/постер/плеер работают (passthrough жив).
7. `/filters/off` -> перезагрузить релизы: полный список; `/filters/on` вернуть.

Внимание: origin `127.0.0.1:8180` - отдельное localStorage от lampa.mx,
потребуется заново войти в cub-аккаунт (или добавить избранное заново).
